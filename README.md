# Better HSC Papers

https://planeman653.github.io/betterhscpapers/

Static site (GitHub Pages) of HSC trial-paper questions sorted by syllabus — topic, subtopic and dot point —
with difficulty ratings, worked solutions / sample answers and a PDF builder.

- Mathematics Advanced, Extension 1, Extension 2 — NESA 11–12 (2024) syllabuses
- Physics, Chemistry — NESA Stage 6 (2017) syllabuses, Year 12 modules 5–8

Layout:

- `index.html` and one page per course (generated by `scripts/make_pages.py`)
- `assets/` — `app.js`, `style.css`, cropped diagrams in `assets/img/<paper-id>/`
- `data/syllabus/` — parsed syllabuses (`scripts/parse_syllabus.py` for maths, `scripts/parse_science_syllabus.py` for science)
- `data/papers/<course>/<paper-id>.json` — one file per indexed paper (source of truth)
- `data/build/` — generated by `scripts/build.py`; what the site loads
- `data/ledger.json` — THSC papers already indexed or skipped
- `INDEXING.md` — the daily indexing procedure (10 papers a day)

Source papers: THSC Online (thsconline.github.io). Content outside the syllabus is dropped.
The previous HSC Paper Builder code is kept on the `legacy` branch.
